# Elegance Universe

Modern ZAR storefront for health, beauty, winter essentials and smart tech.

## Live site

1. Open [Pages settings](https://github.com/Sepengpholo/elegance-universe/settings/pages)
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Save

**https://sepengpholo.github.io/elegance-universe/**

## Features

- Hero carousel + auto-rotating collections
- Spotlight: Laser Level, Dual Lens 4K Dash Cam, Car Air Purifier
- Product grids with filters, quick-view, cart drawer, search
- Light/dark theme, ZAR pricing

## Local

Open `index.html` in a browser.
